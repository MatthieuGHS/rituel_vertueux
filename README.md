# Rituel Vertueux — v0

Site vitrine + boutique fictive de la marque Rituel Vertueux (projet d'études, **aucune commande réelle**).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build && npm run preview
```

Compte de démonstration : `demo@rituelvertueux.fr` / `motdepasse`.
